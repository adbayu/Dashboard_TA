# Virtual Pet artwork

Only user-supplied character artwork is used. Supplied files remain unchanged: do not generate, crop, filter, recolor, or re-encode them.

Supported species:

- Nila, Gurame, and Kangkung: levels 1–4 each have five supplied condition GIFs: normal, senang, sedih, kepanasan, and kedinginan.

No character files for other species belong in this feature. The SVG files in `ikon-sensor/` are sensor icons, not character art, and remain available.
