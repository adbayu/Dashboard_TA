# Audit antislop 005: implementasi IoT Minggu 1

Tanggal: 4 Oktober 2026

Objek audit: perubahan konten sejak commit `3561116` yang dibuat atau diedit untuk Gate Minggu 1, termasuk migrasi/backend v1, tes integrasi, firmware, dokumentasi firmware, perubahan lint di `src/`, serta pembaruan `PILOT-SETUP.md` dan dokumen IoT yang diedit, termasuk UI/UX dan peta layar.

Mode: audit setelah implementasi. Pemilik meminta semua temuan langsung diperbaiki. Temuan berikut dicatat sebelum perbaikan.

Prioritas mengikuti format audit sebelumnya: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock/Craftsmanship = LOW.

## Yang lolos

- R-02: tidak ada em dash baru pada `firmware/`, `server/`, atau dokumen IoT yang diedit. Em dash yang sudah ada pada komentar `src/` tidak ditulis ulang; perubahan A4 hanya menambahkan direktif lint.
- R-17, R-36, R-38: angka batas uji mengikuti Test Plan; batas TDS dan model perangkat tetap diberi label sementara, tanpa klaim bahwa alat fisik sudah diuji.
- R-31: alasan suppress lint ditulis di dekat tiap baris, hanya untuk `react/only-export-components` dan fallback `react/set-state-in-effect`. Kode runtime dan tampilan tidak berubah.
- C-2: perubahan firmware mempertahankan jalur ingest v1/v2 dan tes PostgreSQL memeriksa retry serta payload buffer untuk empat tipe sensor.
- R-35: SmartApp dan Pilot dibuka di Chrome headless. Tidak ditemukan pesan error JavaScript pada console halaman. Pilot menampilkan peringatan API tidak merespons karena backend tidak dijalankan untuk smoke test; itu bukan console exception. Tidak ada perubahan tampilan pada A4.

## Langkah berikutnya

Perbaiki AS-005-01 sampai AS-005-04, lalu catat bukti per temuan di `audit-005-2026-10-04-followup.md` dan jalankan ulang verifikasi akhir.
