## Yang lulus

- Baseline sebelum perbaikan pada sesi audit: `npm run test:pilot`, `npm run test:v1`, dan unit test frontend berakhir dengan exit code 0. Ini bukan verifikasi setelah perbaikan.
- Pasangan teks yang diperiksa dengan checker lulus WCAG AA: `#191C1D` pada `#F8FAFB` 16.37:1; `#404943` pada `#F8FAFB` 8.91:1; `#E9EEEA` pada `#171C19` 14.70:1; `#BAC7BE` pada `#171C19` 9.86:1; `#95D4B3` pada `#171C19` 10.15:1; dan putih pada `#0F5238` 9.19:1. Kegagalan batas komponen dicatat sebagai AS-007-01.
- Pemeriksaan statis route, error, dan kontrak menemukan path rotasi aktual `/api/v1/devices/:id/credentials/rotate` pada `server/v1/devices.ts:294-315`, sesuai dengan `docs/iot/03-api-contract.md:162-168`; penyimpangan dari bentuk singular dijelaskan di Contract 6.3. Contract 6.7 dan `docs/iot/adr/0003-sse-untuk-live-update.md:15-17` menyebut fetch streaming dengan `ReadableStream`, bukan `EventSource`, serta menyatakan tidak ada endpoint atau query catch-up baru. Changelog mencakup perubahan backend dan frontend Minggu 3, dan spesifikasi UX 4.3/5.3 sejalan dengan implementasi yang diperiksa.
- Pemeriksaan kode di `src/components/iot/SandboxPanel.jsx:150-163` dan `src/pages/Monitoring.jsx:113,243,695` menemukan label teks Sandbox pada record terkait. `src/services/iotStream.js:228-241` baru menetapkan status `Live` setelah respons HTTP 200 dengan body yang menyediakan `getReader`. Monitoring memakai data API untuk nilai dan ringkasan; tidak ditemukan klaim pelanggan, testimoni, atau metrik pemasaran rekaan pada layar yang diperiksa.
- Scan aman pada diff tambahan menemukan 0 key penuh berpola `jf_live_` atau `jf_test_`, 0 nilai 64-hex penuh, 0 `console.log` baru, dan 0 TODO baru tanpa penanda Q1-Q7. Ada satu field credential literal pada fixture test di `server/v1.test.ts`; nilainya tidak ditampilkan. Index Git dan riwayat tidak memiliki path `.env` yang persis.

- Browser tidak dapat menjalankan harness karena koneksi `TEST_DATABASE_URL` ditolak pada port 55432. Database development yang berbeda tidak dipakai sebagai pengganti.
- R-27 dan R-35: belum menguji loading, kosong, error, dan berisi pada tiap tab Monitoring, Log kejadian, panel Sandbox, modal rotasi credential, dan alur klaim device. Belum mengklik tab, filter kejadian, Muat ulang, setiap skenario sandbox, rotasi, atau kontrol salin.
- R-32: belum mengukur urutan Tab pada Monitoring dan Developer, perpindahan fokus ke dalam modal rotasi, focus trap, penutupan Escape, dan pemulihan fokus.
- R-34 dan R-25: tema terang dan gelap belum diperiksa pada halaman yang dirender di browser. Pengukuran checker di atas memakai warna dan komposit CSS yang teridentifikasi, bukan pengamatan browser.

- Uji perangkat keras fisik tetap menunggu pelaksanaan terpisah. Ini bukan temuan perangkat lunak.
